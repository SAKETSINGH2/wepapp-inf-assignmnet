## Project Structure

- **client/:** Contains the frontend code of the application.

- **server/:** Contains the backend code of the application.

```
# Clone the repository
- git clone https://github.com/SAKETSINGH2/wepapp-inf-assignmnet.git

# Navigate into the project directory
- cd wepapp-inf-assignmnet

# Move into the frontend directory
- cd client

# Install dependencies
- npm install


# Move into the backend directory
- cd ../server

# Install dependencies
- npm install

# Navigate to the backend directory (if not already in it)
- cd server

# Start the server
- npm start

# Navigate to the frontend directory
- cd ../client

# Start the frontend
- npm start
```

### Backend API Endpoints

- **Signup:** POST https://authapp-0ut5.onrender.com/backend/api/user/signup
- **Login:** POST https://authapp-0ut5.onrender.com/backend/api/user/login
- **Reset Password:** POST https://authapp-0ut5.onrender.com/backend/api/user/reset_password
- **Forgot Password:** POST https://authapp-0ut5.onrender.com/backend/api/user/forget_password
